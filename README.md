# Gestión de Ventas de Buses Intermunicipales
Programa que gestiona la venta de M buses intermunicipales, almacenando las ventas diarias en una matriz. Permite identificar el bus con mayores y menores ganancias semanales, así como el día de mayor venta para cada bus. Además, incluye un procedimiento para aumentar en un 20% las ventas diarias que están por debajo del promedio.
